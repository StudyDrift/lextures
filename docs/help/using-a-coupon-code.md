# Using a coupon code

Course creators can share a short code (for example `LAUNCH25`) that lowers the price of a paid marketplace course. Codes are course-scoped: a code from one course will not work on another.

## Where to enter it

1. Open the course on the marketplace (or follow a share link that already includes `?coupon=…`).
2. On the course detail page, expand **Have a coupon code?**, type the code, and choose **Apply**.
3. Confirm the new total (list price struck through, discounted amount primary) before you continue to checkout.
4. The buy button label includes the discounted price (for example **Buy — $30.00**).

Share links apply the code for you when the page loads — you should see the discounted price without retyping. Links work for signed-out visitors: after you sign in or sign up, the discount is restored for that course.

Marketing pages on lextures.com may say the code will be applied at checkout; the discounted total is confirmed in the app storefront.

## What you pay

The amount shown after a successful apply is what you will be charged before tax. The platform never trusts a price typed into the browser; the server recomputes the discount from the code and the course's list price.

## 100% off (free with a code)

If a code makes the course free, you go straight into the course — no card step. Your access is recorded as a coupon grant (distinct from a course that was always free).

## Why a code might not work

| Message (approx.) | Meaning |
|---|---|
| Not found | Wrong code, or the code belongs to a different course |
| Not active yet | The creator set a start date in the future |
| Expired | The end date has passed |
| No seats left | The creator's total redemption limit was reached |
| Already used | You already redeemed this code (per-person limit, usually once) |
| Inactive | The creator paused or archived the code |
| Already owned | You already have access — the seat is not consumed |
| Currency mismatch | Fixed-amount codes must match the course currency |

If a code stops working between preview and checkout, you will be told why and can continue at the full price if you still want the course.

After too many failed attempts you may see a cool-down message and need to wait before trying again.

## On phone and tablet

Share links with `?coupon=` open the course in the Lextures app when it is installed. Typing a code works the same way as on the web when coupons are enabled for your organization.

| Platform | What happens |
|---|---|
| **Android** | Full parity with the web: enter or auto-apply a code, see the discounted total, and complete checkout at that price (including free with a 100% code). |
| **iPhone / iPad** | **100% off** codes enroll you in the app with no App Store purchase step. **Partial discounts** cannot change the App Store fixed price, so the app shows the validated discount, lets you **Copy code** or **Continue in browser**, and still offers an explicit **Buy at full price** option in the app. |

## Refunds

If you refund a purchase that used a coupon, the seat is released according to the coupon's rules and the discount no longer counts toward the creator's performance totals. Your access ends when the refund is completed.

## Privacy

Coupon codes are not personal data. Your purchase receipt may show the code and the discount amount so you can see what you paid.
