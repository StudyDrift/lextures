# Glossary authoring

Each entry needs a 40–60 word definition, a one-sentence version, worked example, at least 150 words of page-specific guidance, a relevant Lextures link, three to six related terms, a primary source, and a registered expert reviewer. Definitions should state boundaries and avoid promotional claims.

Run the utility checker and marketing tests before publication. Correct factual errors in the source record, update the review date, rebuild, and verify the copyable definition and structured data in emitted HTML.
