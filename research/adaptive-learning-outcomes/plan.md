# Analysis plan: The Adaptive Learning Outcomes Report

Status: preregistered draft — no extraction or analysis authorized  
Planned slot: December 2026

Primary questions are whether adaptive delivery is associated with mastery, time-to-mastery, and
retention in existing holdout cohorts. The final preregistration must define estimands, cohort
construction, confounder handling, missingness, confidence intervals, and sensitivity analyses.
Results will be described as observational or as an internal experiment according to the actual
assignment mechanism, never as a controlled trial without random assignment. The US-heavy,
self-selected Lextures population limits generalization.

All gates and publication requirements in `../templates/analysis-plan.md` apply. The DPIA is not yet
approved, so the pipeline must not run.
